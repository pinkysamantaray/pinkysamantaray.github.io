# Portfolio Website Project Plan

This document outlines the plan for creating a personal portfolio website.

## Technology Stack

*   **Framework:** Vite + React
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS

## Features

*   Single-page layout
*   Fixed left sidebar with profile picture, contact details, and CV download button
*   Right side sections with data content
*   Custom Theme toggle (light/dark mode)
*   Responsive design

## Sections

*   About Me
*   Skills
*   Experiences
*   Tech Stacks
*   Projects
*   Education
*   Licenses & Certificates
*   Recommendations
*   Links
*   Contact Me
